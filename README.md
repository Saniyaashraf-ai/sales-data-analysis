# Sales Data Analysis 📊

Exploratory analysis of retail sales data using Python and Pandas, to find which categories, regions and months drive sales.

## 🎯 Business Questions
- What is the total sales amount?
- Which product category sells the most?
- Which regions and sub-categories perform best?
- How do sales change over time?

## 📁 Dataset
- Superstore sales dataset from Kaggle (9,800 orders, 18 columns)
- The dataset file is not uploaded here. Download it from Kaggle to run the notebook.

## 🛠️ Tools Used
Python, Pandas, Matplotlib, Google Colab

## ✅ Recommendations
- Plan stock, staffing and marketing ahead of the September to December peak.
- Focus promotions on the top-selling sub-categories and the top region.

## 🔍 Key Insights
- Total sales were about 2.26 million.
- Technology was the top category (about 827,000), followed by Furniture (about 729,000) and Office Supplies (about 705,000).
- The west region had the highest sales.
- The top sub-categories were phones and chairs.
- Sales were highest in November 2018.
